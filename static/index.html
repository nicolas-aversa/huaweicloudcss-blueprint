La secuencia para dejar la solución lista y cómo mostrarla.

1 · Prepararlo

Una sola vez, para dejar el entorno operativo.

1
Prerequisitos
Cuenta Huawei Cloud con permisos CSS / OBS / VPC / NAT y una VPC + subnet + security group ya creados (anotá los IDs). Una API key de MaaS. En tu máquina: Docker (trae Python y Terraform adentro; el camino nativo con Python 3.11+/Terraform es opcional).
2
Levantar (con Docker)
docker compose up --build y abrís http://localhost:8088. Sin crear nada a mano — la config y el estado quedan en volúmenes.
3
Configurar (⚙ Configuración)
Cargá credenciales OBS (AK/SK), los datos de tu cuenta Huawei (project id, región, VPC/subnet/security group, AZ, bucket) y tu MaaS API key.
4
Preparar el bucket de demos
⚙ Configuración → Preparar bucket de demos: sube los datasets al bucket con los prefijos que esperan las pipelines. Si no tenés la data, generala con los build scripts (build_vertical_datasets.py, build_siem_dataset.py).

2 · Usarlo

Dos caminos, según si querés desplegar o llevarte un kit.

Demo
Despliega de verdad en tu cuenta
Crear pipeline → elegí uno o varios verticales → Desplegar. El primer deploy tarda ~20 min (clusters CSS); los siguientes reusan el entorno. Después, en Mi Infraestructura, completá la puesta en marcha: (1) index template + dashboards, (2) iniciar ingesta, (3) capabilities (chatbot + forecasts).
Builder
Traé el log del cliente → kit
Toggle “Builder (tu log → kit)” → pegás unas líneas → GLM arma el pipeline y detecta los campos → elegís la fuente (OBS, Kafka/DMS, Beats, JDBC) → Exportás el Starter Kit (todo en un documento) o desplegás. Ver las guías en docs/guides/.

3 · Explicarlo

Qué mostrar en una demo, en orden.

1
Dashboards
Abrí los dashboards curados: métricas clave, series en el tiempo y el panel de Controls para filtrar sin escribir queries.
2
Chatbot NL → PPL
En el chat de OpenSearch Dashboards preguntá en lenguaje natural (“¿cuántos eventos por estado?”): el agente lo traduce a PPL y responde con el dato real.
3
Forecasts
Mostrá el pronóstico de volumen (RCF) sobre la serie del vertical.
En resumen: pegás un log (o elegís un vertical) → la plataforma arma el pipeline, los dashboards y el chatbot → lo desplegás en CSS. Del log crudo al insight, sin escribir el parseo a mano.
